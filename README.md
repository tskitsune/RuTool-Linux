# RuTool Installer 2.1.1 — Linux

Linux-версия RuTool для Blue Archive. Работают поиск игры, скачивание и установка
перевода, восстановление оригинальных файлов.

**Linux x86_64, glibc ≥2.39.** Qt включён в AppImage.

[Скачать AppImage](https://github.com/tskitsune/RuTool-Linux/releases/tag/v2.1.1-linux) · [Сборка и запуск](client-v2/BUILDING-LINUX.md)

**Steam Deck** — версия 2.0.8 проверена; 2.1.1 требует повторной проверки.

Порт основан на официальном RuTool Installer 2.1.1.
Добавлены новый интерфейс и отдельная установка русских экранов загрузки
для Premium. [Изменения и проверки](client-v2/docs/APPIMAGE-2.1.1-VALIDATION.md).

1. Переключись в режим рабочего стола (Desktop Mode) и скачай AppImage по ссылке выше.
2. Открой свойства скачанного файла и разреши его запуск как программы.
3. Запусти AppImage двойным щелчком.

Оригинальный проект: [shiroshy/RuTool](https://github.com/shiroshy/RuTool).
