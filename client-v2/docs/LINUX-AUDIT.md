# Устройство Linux-порта

Linux-версия использует общий код установки, криптографии и QML-интерфейса.
Отдельная платформенная реализация отвечает за работу с файлами, локальное
шифрование и поиск игры.

| Область | Реализация на Linux |
| --- | --- |
| Сборка | Нативный Qt executable; Windows launcher и updater собираются только на Windows |
| Файлы и процессы | `/proc`, `openat` с `O_NOFOLLOW`, `flock`, `renameat`, `fsync` |
| Локальные данные | AES-GCM, случайный ключ с правами `0600`, идентификатор на основе `machine-id` и uid |
| Криптография пакетов | Общий PortableCrypto/Mbed TLS: PBKDF2-SHA256, AES-GCM, ECDSA P-256/P1363, SHA-256 |
| Установка | Общие транзакции, хеши и журналы отката; регистр символов в путях учитывается |
| Поиск игры | Библиотеки Steam, manifests, Flatpak и каталоги Proton; ручной выбор папки |
| Данные и настройки | Каталоги XDG; запись внутрь AppImage не требуется |
| Интерфейс | Общие QML-файлы; при отсутствии Windows-шрифтов используется системный шрифт |
| Дистрибутив | AppImage с Qt, QML, плагинами и OpenSSL |

## Конфигурация и шифрование

Публичные `installer-keys.json` и `update-public.der` включены в AppImage.
Файл `${XDG_CONFIG_HOME:-$HOME/.config}/rutool/installer-keys.json` позволяет
переопределить штатную конфигурацию.

Подписи пакетов, хеши, TLS и серверная аутентификация проверяются общим кодом.
Локальные данные Linux имеют формат `RULOC1` и несовместимы с Windows DPAPI.
Для восстановления сохранённых кодов и журналов нужен `private/local.key`.
Ключ защищён правами доступа ОС; другой процесс того же пользователя может
иметь к нему доступ.

## Обновления и дополнения

В 2.1.1 общий код обновлений использует API `application/v2/latest` и
`application/v2/candidate`, а `update-public.der` содержит новый публичный ключ.
Windows launcher, DLL payload и updater в Linux-сборку не входят. Для обновления
Linux-версии нужно заменить AppImage вручную.

Русские экраны загрузки — отдельное Premium-дополнение. Каталог передаёт размер
и SHA-256; загрузка с Bearer-кодом идёт через
`/api/installer/premium/addons/loading-screens`. Перенаправления запрещены,
доступ Premium повторно проверяется перед записью.

Формат `.rudp` имеет заголовок `RUTD1` и copy/literal записи с little-endian
длинами и смещениями. Размер ограничен 64 MiB, длина результата должна совпасть
с оригиналом. Исходный и конечный SHA-256 bundle зафиксированы в коде.
Формат контейнеров `.rut`, подписи и PortableCrypto не изменились.

Дополнение устанавливается отдельной транзакцией с сохранением оригинала.
Каталог `Preload/Windows/` в пути bundle — имя ресурса игры, используемого также
через Proton. Копия дополнения хранится отдельно от копий основного перевода.
Интерфейса восстановления дополнения в upstream 2.1.1 нет; кнопка восстановления
основного перевода его не удаляет.

## Файловые операции

Блокировки POSIX согласуют работу экземпляров RuTool, но не мешают стороннему
процессу игнорировать их. Платформенные файловые операции открывают компоненты
путей без перехода по символическим ссылкам. Найденные Steam-алиасы приводятся
к реальному пути.

Замена файла выполняется в пределах одной файловой системы. Перенос между
файловыми системами завершается ошибкой `EXDEV`. Часть общего кода использует
Qt I/O, поэтому полная защита от одновременной подмены каталогов не обеспечивается.
Каталог игры должен принадлежать пользователю и не быть доступным для записи
недоверенным процессам.

## Тесты

Linux-тесты проверяют криптографию, Steam/Proton discovery, блокировки, замену
файлов, откат, восстановление, загрузку и обработку сетевых ошибок. Для 2.1.1
добавлены дельты RUTD1, Premium-загрузки дополнения и восстановление журналов
с одной/тремя целями. Отдельные проверки загружают production QML и проверяют
настройки, темы, каталог и панели без сети и обращения к игре.

Фикстуры синтетические. Для подписей используется общеизвестный тестовый
EC scalar 1; производственные приватные ключи не нужны. Фикстуры отмечены
как binary в `.gitattributes` и не включаются в AppImage.

Результаты сборки 2.1.1: [APPIMAGE-2.1.1-VALIDATION.md](APPIMAGE-2.1.1-VALIDATION.md).
